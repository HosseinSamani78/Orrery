# Glossary

- **Board**: a named collection of timers, optionally organized into phases.
- **Timer**: a single running/paused/completed timing instance of a given timer type.
- **Timer type**: one of the six v1 types — countdown, quick start, count up, Pomodoro, interval, stopwatch.
- **Run**: one execution of a timer from start to completion/reset.
- **History entry**: a record created when a timer completes, for later review.
- **Preset**: a saved Board configuration that can be applied to create a new Board.
- **Widget**: a Home Screen / desktop widget reflecting running timers and their completion.
- **Free tier**: the limits a copy runs under until Pro is purchased — one Board, three concurrent Timers, no Widget.
- **Pro**: the one-time StoreKit purchase that lifts the free limits and unlocks Widgets.

Orbit metaphor is branding/visuals only; do not rename domain terms to space words.
